# Лабиринт

Текстовая приключенческая игра, в которой вы исследуете таинственный лабиринт, 
решаете загадки и ищете легендарное сокровище.

## Установка

make install

## Запуск

make project

## Описание игры 

Игрок исследует таинственный лабиринт, решает загадки, собирает предметы
и пытается найти легендарное сокровище.

## Команды

north/south/east/west - движение в направлении

go <direction> - альтернативное движение

look - осмотреть текущую комнату

take <item> - взять предмет

use <item> - использовать предмет из инвентаря

inventory - показать инвентарь

solve - решить загадку в комнате

help - показать список команд

quit - выйти из игры

## Цель игры

Найти сокровище в treasure_room. 
Для этого надо попасть в комнату, которая закрыта дверью с тремя замками 

## Особенности

Случайные события при перемещении

Уникальные реакции в особых комнатах

Альтернативные варианты ответов на загадки

Система ловушек и предметов

## Условия победы

Получить три ключа в комнатах сюжетных персонажей: Королева, Архивариус, Страж.
